符合条件的学生可以申请 JetBrains 教育许可证，用于学习和教育活动。它不是通用商业许可证，也不是取得一次后永久有效；仍在读时需要按要求续期。

本文依据 [JetBrains Education](https://www.jetbrains.com/community/education/#students) 与当前教育许可条款整理，最后核对于 2026 年 9 月 1 日。

## 选择一种验证方式

JetBrains 的页面会根据地区和账号提供可用方式，常见路径包括：

- 使用已被识别的学校邮箱；
- 通过已验证的 GitHub Education 身份；
- 使用官方支持的学生身份服务；
- 按要求提交在读文件。

如果学校邮箱未被识别，不要反复换域名。改用页面提供的验证方式，并保证账号姓名、学校名称和证明文件一致。

## 申请后检查

1. 登录 JetBrains Account。
2. 确认许可证名称、覆盖产品和到期日。
3. 在 Toolbox App 或 IDE 中使用同一账号激活。
4. 只在本人设备和许可允许的场景中使用，不共享账号或激活信息。

## 续期与毕业

在资格仍有效时，按账号页提示重新验证。毕业或不再符合条件后，应为商业工作选择个人或企业许可，并把 IDE 设置、插件列表和项目代码迁移到个人账号控制的存储。

如果你还没有 GitHub 学生身份，可先看[GitHub Student Developer Pack 申请排查](/blog/github-student-developer-pack-guide/)。
