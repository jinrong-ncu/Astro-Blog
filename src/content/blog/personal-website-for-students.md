学生个人网站最小版本只需要三类内容：一句清楚的自我定位、三到五个可验证项目、一个稳定联系方式。先把它部署到公开 URL，再决定要不要加博客、评论或后台。

## 一个周末的上线范围

### 首页

写清你正在做什么、希望别人先看哪个项目，以及如何联系你。不要堆满技能图标。

### 项目页

每个项目至少包含问题、你的职责、关键决策、结果和代码或演示链接。没有上线链接时，说明运行方式与限制。

### 关于页

只写可公开验证的信息：学习方向、关注问题、更新原则和联系方式。住址、证件、学校内部系统截图不应公开。

## 技术方案

如果内容主要是文字和项目，静态站点通常足够：

1. 用 Astro 或任意熟悉的静态站点工具；
2. 内容放在 Git 仓库中；
3. 通过 Vercel 或 Cloudflare Pages 自动构建；
4. 绑定个人域名并启用 HTTPS；
5. 添加 sitemap、canonical 和基础元数据。

不要为了联系表单就先搭数据库。邮箱链接或经过隐私评估的表单服务更容易维护。

## 上线前检查

- 手机和桌面都能阅读；
- 所有项目链接在退出登录后仍可访问；
- 仓库没有密钥和个人材料；
- 404、favicon、标题和分享图正常；
- 简历与网站中的时间、项目名称一致；
- 网站能从首页链接到每个重要页面。
