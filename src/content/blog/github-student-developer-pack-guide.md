申请 GitHub Student Developer Pack 的关键不是邮箱后缀，而是让 GitHub 能确认你当前在符合条件的教育机构就读。先完善账号安全与个人信息，再提交清晰、仍在有效期内的证明。

本文最后核对于 2026 年 9 月 1 日。具体材料与权益以 [GitHub 官方申请说明](https://docs.github.com/en/education/about-github-education/github-education-for-students/apply-to-github-education-as-a-student)和 [Student Developer Pack](https://education.github.com/pack) 页面为准。

## 申请前准备

- GitHub 账号启用双重验证；
- 账号资料中的姓名尽量与证明材料一致；
- 添加并验证学校邮箱；无法使用时准备替代在读证明；
- 准备学生证、在读证明或课程注册材料，确保学校、姓名和有效日期清楚可见。

## 提交流程

1. 登录 GitHub Education，选择学生身份。
2. 选择学校并填写用途。
3. 按页面要求验证学校邮箱或上传证明。
4. 提交后等待审核，不要用多个账号重复申请。
5. 通过后从 Pack 页面逐项领取真正需要的权益，并记录各合作方自己的条款与到期日。

## 被拒时按原因修正

- **图片模糊或裁切**：重新拍摄完整文件，避免反光和遮挡。
- **无法确认当前在读**：补充当前学期、预计毕业时间或课程注册信息。
- **学校名称不一致**：使用文件上的正式英文名称，不要只写简称。
- **邮箱无法使用**：按照页面提供的其他验证路径提交，不要购买学校邮箱。
- **权益没有立即出现**：先确认 Education 状态已通过，再查看合作方是否需要单独注册。

Student Pack 的合作项目会变化，不要把第三方清单中的旧权益当作长期承诺。GitHub 也会要求重新验证学生身份。
