选学生软件时，先问“我要完成什么任务”，再看免费版是否够用。不要把工作流建立在来源不明的教育账号、破解软件或毕业后立即失效的校园存储上。

这份清单最后核对于 2026 年 9 月 1 日。它不承诺每项付费功能免费，而是给出可长期迁移的起点。

## 六类任务的稳妥起点

| 任务 | 免费起点 | 何时再申请教育计划 |
| --- | --- | --- |
| 文档与表格 | LibreOffice、Microsoft 365 网页版 | 学校明确分配 Microsoft 365 Education 许可 |
| 论文与引用 | Zotero | 团队存储或机构数据库确有需要 |
| 编程 | Visual Studio Code、GitHub 免费版 | 需要 JetBrains IDE 或 GitHub Education 权益 |
| UI 与展示 | Figma Starter、Canva Free | 符合各自教育资格或学校已采购 |
| 文件同步 | 系统文件夹 + 外置盘 + 一个云端副本 | 学校 OneDrive 只作为额外副本 |
| 个人网站 | Astro、GitHub、静态托管 | 流量或团队需求超过免费额度 |

## 选择标准

1. **能导出通用格式**：Markdown、PDF、CSV、Git 仓库比封闭格式更容易迁移。
2. **账号归个人控制**：学校邮箱不应是唯一登录或恢复方式。
3. **免费额度写在官方页面**：价格和限制会变，申请当天再检查。
4. **先完成一个真实任务**：不要为了“薅权益”安装整套用不到的软件。
5. **至少有两份备份**：同步不是备份，误删会同步到所有设备。
